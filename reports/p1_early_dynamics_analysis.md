## 5. 预注册判读

1. **CPI 的变化定位**：s1 在 **250→500**、s2 在 **500→750**（EMA 口径；raw 口径 s1 同）。两 seed 的定位落在同一 **250–750 窗口**，方向一致（均为下降），不构成 unstable。
2. **形态 = 连续衰减，非瞬时阶跃**：250→500、500→750、750→1020 存在多个显著相邻 Δ（两 seed 交叉显著），0→250 完全平台。衰减主体集中在 warmup 后期 LR ≈ 1.5e-5 → 3e-5 爬升段；**LR 低于 ~1.5e-5 时（前 250 步）compatibility 不动**。
3. **1020→2500 为平台**：CPI 的相邻 Δ CI 全部含 0（s1-raw 有轻微回升噪声），两 seed 一致。v4.1 的"主要变化在第一个 1020-step checkpoint 之前出现"被 dense 网格确认并细化：**变化窗口 ≈ 250–1020，其中大部分在 250–750 完成**。
4. **OrderGap 动力学更早启动**：0→50 已显著（+0.03 nats，四口径一致），100→1020 连续大幅下降；s2 的 OG 在 1020→2500 仍显著下降（s1 平台）。OG 对早期权重扰动比 CPI 敏感（度量全局顺序敏感性 vs 局部 swap 不一致，预期不同步）。
5. **G1 与 CPI 同步**：masked NLL 从 100 步开始改善、500–1020 加速、2500 达 3.94——task loss 改善与 compatibility 收缩的时间窗重叠。
6. **signed δ 全程无系统性偏离**：attenuation 是 swap-incompatibility 幅度的对称收缩，不是方向性 bias 的出现。
7. **raw vs EMA**：轨迹平行。EMA 在 2500 处略平滑于 raw（s2-raw 有 +0.016 回升噪声而 EMA 无），与 EMA effective decay 在 warmup 区间（审计 ②，n=1020 时 0.9913）的平滑预期一致。

## 6. 分桶观察（EMA 口径，供叙事用，非预注册判据）

- **pair_distance**：下降主要由近距离对贡献 —— d[1,4] 从 0.68 → 0.60–0.62（两 seed），d[15,41] 仅 0.11 → 0.08。n-gram 相邻耦合的 swap 不一致被 SFT 优先削弱。
- **σ**：σ=3.0 桶下降最多（0.48 → 0.40），σ=0.5 桶几乎不动——高噪声（强腐蚀）条件下的条件预测不一致被优先修正。

## 7. 与 v4.1 的衔接

- v4.1 判决 B_DIAGNOSTIC_ONLY 永久固定，不受本报告影响。
- v4.1 的稀疏采样（0 与 1020）暗示"瞬时阶跃"；P1 密集网格显示实际是 **warmup 后期启动、~700 步窗口内完成的连续衰减**。v4.1 观察本身（"主要变化在 1020 前出现"）被 P1 确认。
- 对 P2 的启示：跨设置复现若继续观察"早期窗口衰减"，P2 的 3 个分析点（1020/5100/10200）无法定位窗口 → 叙事时只做"是否存在稳定 Δ"，不做动力学形态断言（协议 §4 已如此设计，无需修订）。
